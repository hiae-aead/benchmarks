# Benchmark Visualizer

A Python tool for visualizing cryptographic algorithm benchmark results from the IETF benchmarking suite.

## Overview

This tool processes CSV benchmark outputs from various authenticated encryption algorithms (AEGIS, AES-GCM, HiAE, ROCCA-S) and generates comparative performance visualizations.

## Features

- **Bar charts at 65536 bytes**: AEAD encryption against AEAD decryption, in Gbps and in cycles per byte
- **Line plots across message sizes**: from 64 bytes to 64 KB, for the keystream path and for both AEAD directions
- **Automatic CSV parsing**: handles both the CSV and the table-formatted benchmark output
- **Performance summary table**: keystream and AEAD numbers side by side in the terminal

Each benchmark prints two sections. The keystream section ("Encryption Only Performance") measures the raw
keystream XOR, where decryption is literally the same operation as encryption, so it is plotted once. The AEAD
section is where the two directions come apart, so both are plotted there.

## Installation

```bash
# Using pip
pip install pandas matplotlib numpy

# Using uv (if available)
uv sync
```

## Usage

```bash
python plot_performance.py <csv_directory>

# Example:
python plot_performance.py ../csvs
```

The script expects a directory containing CSV files generated by the benchmark tools. Each CSV file should follow the naming convention: `<algorithm-name>.csv`

## Input Format

The tool parses benchmark files that contain, per section:
- Size (bytes)
- Operation (encrypt/decrypt; the ROCCA-S MAC row is skipped)
- Performance metrics (Gbps, MB/s, Cycles/Byte, CV%)

Both output shapes work: the `--csv` output, and the pipe-delimited tables the benchmarks print by default.

## Output

The tool writes PNG images to the parent directory of the CSV folder:

1. `throughput_comparison_<dirname>.png` - AEAD encryption against decryption at 64 KB
2. `efficiency_comparison_<dirname>.png` - the same comparison in cycles per byte
3. `encryption_throughput_<dirname>.png` - keystream throughput across message sizes
4. `encryption_efficiency_<dirname>.png` - keystream cycles per byte across message sizes
5. `aead_encryption_throughput_<dirname>.png` - AEAD encryption across message sizes
6. `aead_decryption_throughput_<dirname>.png` - AEAD decryption across message sizes

## How It Works

1. **Parsing**: `section_rows()` locates a named section in either output format, and `parse_csv_file()` turns it into a frame
2. **Aggregation**: every CSV file in the directory is read and combined with pandas
3. **Visualization**: matplotlib draws the bar and line charts, with the fastest algorithm first so the legend follows the curves
4. **Metrics**: throughput in Gbps (higher is better) and cycles per byte (lower is better)

## Dependencies

- pandas >= 2.0.0 - Data manipulation and analysis
- matplotlib >= 3.7.0 - Plotting and visualization
- numpy >= 1.24.0 - Numerical operations

## Notes

- The tool handles both output formats produced by the benchmark programs
- All plots use consistent colors and styling for easy comparison
- Bars and legends are ordered by throughput, so the ranking is readable at a glance
- Message sizes are displayed on a log scale (base 2) for better readability
